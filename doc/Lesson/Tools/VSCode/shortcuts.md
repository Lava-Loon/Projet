# Raccourcis Clavier VS Code (Visual Studio Code)

Voici une liste des raccourcis les plus utiles pour gagner du temps lors du développement.

## Général
- `Ctrl + Shift + P` : Ouvrir la palette de commandes (accès à toutes les fonctionnalités)
- `Ctrl + P` : Ouverture rapide de fichiers (rechercher par nom)
- `Ctrl + ,` : Ouvrir les paramètres
- `Ctrl + Shift + \`` : Ouvrir/Fermer le terminal intégré
- `Ctrl + B` : Afficher/Masquer la barre latérale

## Édition de code
- `Ctrl + /` : Commenter / Décommenter la ligne
- `Alt + ↑ / ↓` : Déplacer la ligne actuelle vers le haut ou le bas
- `Shift + Alt + ↑ / ↓` : Copier la ligne actuelle vers le haut ou le bas
- `Ctrl + D` : Sélectionner l'occurrence suivante du mot sous le curseur
- `Ctrl + Shift + L` : Sélectionner toutes les occurrences du mot sous le curseur
- `Ctrl + Z` : Annuler
- `Ctrl + Y` : Rétablir (ou `Ctrl + Shift + Z`)
- `Ctrl + Space` : Déclencher les suggestions (IntelliSense)

## Navigation
- `Ctrl + G` : Aller à une ligne spécifique
- `Ctrl + F` : Rechercher dans le fichier
- `Ctrl + H` : Remplacer dans le fichier
- `Ctrl + Shift + F` : Rechercher dans tout le projet
- `F12` : Aller à la définition
- `Alt + ← / →` : Revenir en arrière / aller en avant dans l'historique de navigation

## Gestion des fenêtres
- `Ctrl + \` : Diviser l'éditeur (split view)
- `Ctrl + W` : Fermer l'onglet actuel
- `Ctrl + K Z` : Mode Zen (sans distraction)
