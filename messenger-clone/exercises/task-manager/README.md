# Exercice 9 : Le Gestionnaire de Tâches (Expert Tailwind & React) 📝🎨

C'est toi qui fais tout cette fois-ci : la **logique** ET le **style**. Pas de code pré-rempli, juste toi et ton talent.

## Ton objectif :
Créer une application de tâches interactive.

### La Structure (TypeScript) :
Dans `TaskManager.tsx` :
- Une interface `Task` avec `id`, `title`, `isDone`.
- Un `useState` pour la liste.
- Un `useState` pour le texte du nouvel input.

### Le Lexique Tailwind (Ton aide-mémoire) :
Utilise ces classes pour construire ton interface :

| Catégorie | Classes utiles | Effet |
| :--- | :--- | :--- |
| **Conteneur** | `max-w-md mx-auto mt-10 p-6 bg-white shadow-xl rounded-2xl` | Une belle carte centrée |
| **Bordures** | `border border-gray-200 rounded-lg` | Des contours propres |
| **Espacement** | `p-3 mb-4 flex gap-4 items-center` | Aligner et aérer |
| **Typographie** | `text-2xl font-bold text-gray-800` | Un titre qui claque |
| **Interaction** | `hover:bg-gray-100 transition cursor-pointer` | Effets de survol |
| **Boutons** | `bg-blue-500 hover:bg-blue-600 text-white px-4 py-2 rounded-lg` | Un bouton style Pro |
| **Suppression** | `text-red-500 hover:text-red-700` | Pour l'icône poubelle |
